About AreaPulse

A map-first prototype for community incident and paranormal reports. The visual direction is inspired by modern social maps: bold floating controls, a map-first home screen and compact bottom navigation.

Prototype

What works now

Interactive worldwide map tiles, explicit place search, Country/County/City/Zone zoom scopes, report categories, local report creation, filtering, saved local data and responsive phone/tablet layout.

Privacy

No background tracking

This build never tracks in the background. Location permission is requested only if you tap the location button, and you can keep using search or the map without granting it.

Data

No live backend yet

Your reports are stored only in this app on this device. A real multi-user release needs authentication, moderation, abuse controls and a backend before reports can be shared publicly.
